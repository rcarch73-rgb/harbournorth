# Harbour North Launch Site

This folder contains a complete responsive landing-page prototype and the first production-ready brand and marketing direction.

## Files

- `index.html` — landing page
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and prototype beta form
- `brand-personality.md` — voice and personality standards
- `marketing-plan.md` — practical beta-launch strategy

## Preview

Open `index.html` in any modern browser.

## Before publishing

1. Replace the prototype beta form with a real email-list or CRM integration.
2. Confirm the public domain and contact email.
3. Add final legal pages: Privacy Policy, Terms of Service, and Disclaimer.
4. Replace illustrative figures with approved product screenshots.
5. Add analytics only after deciding on a privacy-compliant approach.
6. Test on Safari, Chrome, Firefox, Edge, iPhone, and Android.
