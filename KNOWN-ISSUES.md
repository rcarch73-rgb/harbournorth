# Known Issues — RC3 Beta 1

1. Full calculation accuracy still needs to be validated against independent manual examples.
2. Browser print settings may need “Print backgrounds” enabled for the full navy report styling.
3. Safari, Chrome, iPad and phone layouts require separate hands-on checks.
4. Older backup files must be tested individually for import compatibility.
5. Browser before-leave warnings use the browser's standard message; custom warning text is not permitted.
6. The static test does not confirm that a user's local browser data will survive browser privacy cleanup or manual storage deletion.
