Harbour North 4.0 RC2 — Branded Command Centre

Built from the working 4.0 RC1 / 3.6 retirement engine.

What changed
- Official Harbour North wordmark and app icon included
- Commercial left navigation with grouped planning, analysis, guidance and system areas
- New sticky command-centre header
- Navy and sea-glass visual system applied across the application
- Retirement Snapshot upgraded to a branded hero experience
- Improved cards, buttons, metrics, timeline and Smart Coach presentation
- Responsive slide-out navigation for phones and tablets
- Privacy and version footer
- Existing retirement calculations, storage schema and planning workflows preserved

Installation
Upload index.html, manifest.json, harbour-north-logo.png, harbour-north-app-icon.png, icon-192.png and icon-512.png to the same GitHub Pages folder.

Recommended test
1. Open Overview and confirm live plan values appear.
2. Use every left-navigation item.
3. Test the mobile menu on iPad/phone width.
4. Export and re-import a backup.
5. Run Setup & Health and the Complete System Test.
6. Print the Retirement Report.
