Harbour North 3.6 — Beta Readiness

Built from the working 3.5.1 release.

New in 3.6
- Beta Readiness Centre inside Setup & Health
- One-click readiness score from 0–100
- Automatic validation of:
  * Household names and birth dates
  * Retirement ages
  * Partner setup
  * Retirement accounts and balances
  * CPP and OAS records
  * Income and spending values
  * Inflation and return assumptions
  * Projection-engine completion
  * Backup status
  * Complete System Test status
- Findings ranked as critical, warning, information or passed
- Direct Review buttons to the relevant planning page
- Five visible beta release gates
- Four-step first-run welcome guide
- Manual preview of the first-run experience
- Responsive mobile and iPad improvements
- Visible busy indicator during readiness scans
- Backup exports recorded as a completed release gate
- Protected readiness scans never alter the active plan
- Complete System Test additions:
  * Beta Readiness Centre
  * Readiness Scan Isolation
  * First-run Guide Controls

Installation
Replace index.html at the GitHub Pages root and fully reload the website.

Recommended test
1. Open Setup & Health.
2. Select Run readiness scan.
3. Review any critical or warning findings.
4. Preview the first-run guide.
5. Export a backup.
6. Run Complete System Test.
